## Bug 1 修复:最左侧侧栏没有滑轮,无法上下移动

根因: .feed-list 用了 `display:flex; flex-direction:column; height:100%;
min-height:0; overflow:hidden` —— 外层 hidden,但中间内容(虚拟分组 +
真分组 + 空态 + 标签列表)都没设 `flex:1 1 0; min-height:0; overflow-y:auto`,
所以溢出时直接被裁,没有滚动条。

修复: 包一个 `.feed-list__body` 容器把中间所有内容(virtuals / groups /
tags / empty)圈起来,body 自身 `flex:1 1 0; min-height:0; overflow-y:auto`。
顶栏 + 底栏 + batch toolbar 保持 `flex-shrink:0` 不滚动。

## Bug 2 修复:... 没有用处,改为批量删除

根因: ... 菜单只有"全部展开/全部折叠/删除未使用标签"三个低频操作,
用户更想要"批量删除"这个高频操作。

修复: 重新设计 ... 菜单 + 新增 batch mode:
- ... 菜单只剩"批量管理"入口(点击进入 batch mode)
- batch mode 下:
  - FeedList 顶栏 + body 之间插入 batch toolbar(已选 N / 全选 / 清空 /
    删除选中 / 完成)
  - 每行最左侧出现 checkbox(.feed-list.is-batch .feed-list__checkbox)
  - 点行/checkbox 都切换选中态
  - 批量模式下点击行 = toggle 选中,不再切 feed
  - 批量模式下右键菜单禁用(避免误操作)
- App.tsx 新增 handleBatchDeleteFeeds / handleBatchDeleteTags:
  - 弹 confirm dialog(列出前 5 个名字)
  - 逐个调 window.api.feed.delete / ds.tagDelete
  - 部分成功时 report ok/fail 数
  - 如果当前选中的 feed/tag 在被删列表,回退到 'all'
