feat(feeds-group): 订阅源侧栏真分组(添加组/移动到组/删除组/未分组)

根因
- Feed.groupName 字段在 schema 已有，FeedRepository.update 已支持，
  但 UI 无添加组入口 + 无 IPC 通道拉组列表 + 右键菜单不能移动订阅源
- "未分组"组是兜底（groupName=null），但 UI 没显式标记

后端
- FeedRepository.listGroups(): SELECT DISTINCT group_name 派生所有组名
- FeedRepository.clearGroup(name): 把组内所有 feed 移到未分组
- shared/ipc.ts 新增 FEED_LIST_GROUPS / FEED_CLEAR_GROUP
- 主进程 handler 接入 + 参数校验
- preload 暴露 window.api.feed.listGroups / clearGroup
- DataSource 接口加 feedListGroups / feedClearGroup / updateFeed
- IpcDataSource / MockDataSource 同步实现
  (MockDataSource 加 articleTagMap 持久化 label 关系 + 派生 feedListGroups)

前端
- App.tsx 加 groups state + refreshGroups + handleAddGroup(本地 setGroups)
  + handleMoveFeedToGroup(调 updateFeed) + handleDeleteGroup(调 clearGroup + confirm)
- AddGroupDialog 组件: 文本输入 + Esc/点 backdrop 关闭 + 同名检测
- FeedList:
  - tab=sources 顶栏 + 按钮触发 AddGroupDialog
  - 右键菜单加"移动到..."submenu(扩展 ContextMenu 支持 submenu 字段)
  - 组标题旁加 × 删除按钮(未分组组不可删)
  - 空白组也显示一行提示"还没有订阅源。右键其他订阅源 → 移动到..."
  - grouped 排序: 未分组放最后, 其它字典序
- ContextMenu: 加 submenu 字段(hover 弹出子菜单,边界检测通过 relatedTarget)

smoke
- 新增 scripts/smoke-feeds-group.cjs + npm run smoke:feeds-group
- 17 项关键探针全过: seed feeds / 初始 listGroups / grouped DOM 渲染
  / 添加组 dialog / 移动到组 / 移回未分组 / 删组 IPC / 非法 updateFeed 拒绝
