fix(ui): 批量全选/清空合并为 toggle 按钮 + AI 设置名称"AI 与模型"→"AI模型"

两个 UI 细节优化,根因修复:

## 1. 批量全选/清空合并为 toggle 按钮

根因:
  旧实现 selectAllBatch() + clearBatchSelect() 两个独立函数,对应工具条上"全选"和
  "清空"两个独立按钮。但这两个动作是互斥的(选完才能清空,选完了才能再全选),
  分成两个按钮:
  - 浪费工具条空间
  - 增加用户点击次数(取消全选必须先点清空)
  - 不符合 GitHub / VSCode 等桌面应用批量管理 UX(合并为 toggle)

修复:
  FeedList.tsx:
  - selectAllBatch + clearBatchSelect 合并为 toggleSelectAllBatch()
    - 0 选中 → 点击 → 选所有
    - >0 选中 → 点击 → 清空 selectedForBatch
  - 工具条:删除"清空"按钮,"全选"按钮文字动态切换
    - 0 选中:"全选"
    - >0 选中:"取消全选"
  - testid 从 feed-list__batch-select-all 改为
    feed-list__batch-toggle-select-all(更准确)

  electron/main/index.ts smoke:feeds-group:
  - 删除 batchClearWorks 检查(无清空按钮)
  - 新增 4 项检查覆盖 toggle 行为:
    - batchToggleBtnExists:toggle 按钮存在
    - batchToggleBtnShowsCancelWhenSelected:选后按钮文字"取消全选"
    - batchToggleOffWorks:再点一次 → size=0
    - batchToggleBtnShowsSelectWhenEmpty:取消后按钮文字"全选"

  src/data/mockDataSource.ts:
  - settingsState 加 onboardingCompleted: false 字段
  - 兼容 Phase 4.3 (陈冠中 71abd32) AppSettings 新增 onboardingCompleted 必填字段
  - mock 模式维护的 settingsState 必须跟 IPC 后端 schema 同步

## 2. AI 设置名称"AI 与模型"→"AI模型"

根因:旧名称用"与"字连接 AI 和模型两个概念,显得松散/口语化。
  实际语义是一个统一的"AI 模型设置"区域(Provider + 默认模型 + 摘要/翻译配置),
  合并为"AI模型"更紧凑,符合中文 UI 标签习惯。

修复:2 处文本替换
  - src/pages/UnifiedSettingsPage/UnifiedSettingsPage.tsx:43(统一设置工作区侧栏)
  - src/pages/SettingsPage/SettingsPage.tsx:128(AI 设置页 h1)
  小描述保持不变(默认值与 Provider)

批量管理工具条现在结构:
  [已选 N 个] [全选 / 取消全选] [删除选中] [完成]
  - 之前 4 个按钮 → 现在 3 个按钮
  - 取消全选从 2 步(点全选 → 点清空)→ 1 步(再点 toggle)
